# Third-party protocol references

PadBridge is original integration code built on public protocol research and
open-source libraries.

- Bluepad32 by Ricardo Quesada, Apache-2.0: Bluetooth controller host.
- TinyUSB by Ha Thach, MIT: embedded USB stack.
- PicoSwitch2 by notsosaelin, Apache-2.0: implementation reference.
- retro-pico-switch by bmelanman, MIT: Switch Pro USB protocol reference.
- Nintendo Switch Reverse Engineering by dekuNukem: public protocol notes.

The USB descriptor constants and protocol message formats are interoperability
facts derived from those references. Nintendo is not affiliated with or
involved in PadBridge.
